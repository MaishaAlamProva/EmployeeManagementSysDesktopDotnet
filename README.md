**Employee Management System**  
Developed a desktop-based Employee Management System using C# Windows Forms and the .NET framework to streamline employee record administration. Implemented secure SQL database integration with full CRUD operations for efficient data persistence and retrieval. Designed relational database workflows, optimized UI interactions, and structured the application within a scalable Visual Studio solution architecture.  

**Key Features**
• Employee record creation, update, deletion, and search  
• SQL database connectivity and relational data handling  
• Secure and organized administrative workflow management  
• Optimized Windows Forms UI for desktop usability  
• Version-controlled project structure using Git  

**Technologies Used**  
• C#  
• .NET Framework  
• Windows Forms  
• SQL Database  
• Visual Studio  
• Git & GitHub
